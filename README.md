# Fundamentos de RDD en Apache Spark

Repositorio con la resolución completa de las actividades del documento **Fundamentos de RDD en Spark**:

1. **8 Ejercicios Prácticos resueltos** (`map`, `filter`, `flatMap`, `distinct`, `reduceByKey`, `sortBy`, `saveAsTextFile`, `cache`/`persist`).
2. **Proyecto Práctico: Análisis de Calificaciones** (unificación y limpieza de `notas_mates.txt`, `notas_fisica.txt` y `notas_ingles.txt`, cálculo de promedios, máximos, mínimos, aprobados/suspensos y operaciones de conjuntos con RDDs).
3. **Pregunta de Reflexión:** *RDD vs DataFrame: ¿Cuándo usar RDD?*

## Archivos del Repositorio

- `Entrega_Final_RDD.pdf`: Documento PDF único listo para entrega en Classroom con todas las celdas ejecutadas, sus salidas y la pregunta de reflexión.
- `RDD_Practicas_y_Proyecto.ipynb`: Jupyter Notebook con todo el código y las salidas de ejecución.
- `solucion_rdd.py`: Script en Python/PySpark que ejecuta los 8 ejercicios y el proyecto práctico.
- `logs.txt`, `notas_mates.txt`, `notas_fisica.txt`, `notas_ingles.txt`: Archivos de datos de entrada.
- `output_logs_ip/` y `resultado_logs_ips.txt`: Salida generada por el Ejercicio 5.
